# Mellti FE Backup

발달장애 아동 치료사를 위한 커뮤니티 플랫폼 Mellti의 프론트엔드 개인 백업 레포입니다.

라이브 데모: https://www.melonnetherapists.com

## 디렉토리 구조

- `frontend/`: React 19 + TypeScript + Vite 프론트엔드 앱 (메인 코드)
- `docs/`: 코딩 드릴 가이드·로그, 의존성 맵 등 개인 학습 자료
- `scripts/`: 동기화·자동화 스크립트
- `.claude/`: Claude Code 개인 작업 환경 (프로젝트 메모리)
- `CLAUDE.md`: Claude Code용 프로젝트 컨텍스트

## 현재 상태

MVP 단계이며 활발히 수정 중입니다. 일부 디렉토리(`.claude/`)에 개인 작업 환경이 함께 포함되어 있습니다.

민감 정보(환경 변수, API 키, 토큰)는 `.gitignore`로 제외되어 있으며 히스토리에도 노출된 바 없습니다. 프론트엔드 코드 자체는 본질적으로 클라이언트(브라우저)에 공개되므로 별도 비공개 처리는 하지 않습니다.
