# Mellti FE Backup

발달장애 아동 치료사를 위한 커뮤니티 플랫폼 Mellti의 프론트엔드 개인 백업 레포입니다.

라이브 데모: https://www.melonnetherapists.com

## 디렉토리 구조

`frontend/src/` 기준 (Vite + React 19 + TypeScript)

- `pages/`: 라우트 단위 페이지
- `components/`: 재사용 UI 컴포넌트
- `hooks/`: 커스텀 훅
- `stores/`: Zustand 전역 상태
- `api/`: API 호출 함수
- `types/`: TypeScript 타입 정의
- `utils/`: 유틸 함수
- `lib/`: 외부 라이브러리 래퍼
- `constants/`: 상수 정의
- `mocks/`: MSW 핸들러
