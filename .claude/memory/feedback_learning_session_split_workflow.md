# 긴 학습/복잡한 작업 분할 워크플로우

**규칙**: 한 세션에 다 못 끝낼 학습/디버깅/리뷰는 **(a) 커리큘럼 메모리 파일** + **(b) notepad 트리거 문구** 조합으로 분할. 다음 세션에서 트리거 문구로 정확한 지점부터 재개.

**Why:**
2026-05-13 PR #19 RQ 학습 중 사용자가 "주의력 떨어진다, 저장하고 다음에 check-memory의 문구로 재개할 수 있게 해줘"라고 요청. 5단계 중 4단계까지 끝낸 상태에서 끊고, 다음 세션에서 같은 톤·깊이·진행 위치로 이어가야 했음. 메모리/노트패드만 있고 단계별 합의 내용이 없으면 재개 시 톤 복원 불가능 → 사용자가 다시 처음부터 따라잡아야 함.

**How to apply:**
- 트리거 신호: "주의력 떨어진다 / 저장하고 다음에 이어가자 / 끊고 가자"
- 저장 3종 세트:
  1. **커리큘럼 메모리 파일** (`project_*_learning_*.md` 또는 작업명 기반)
     - 전체 단계 (1, 2, 3, ...) + 각 단계 상태 (✅/⏭/⏸)
     - 각 단계의 **합의 내용 (사용자가 이해한 핵심)** — 재개 시 톤 복원용
     - 다음 시작점에서 다룰 항목 리스트
     - 학습 진행 규칙 (사용자 피드백 반영 — 길이/단계별/소크라테스식 등)
  2. **MEMORY.md `## 작업 관리` 인덱스 한 줄**
  3. **notepad ★ 1순위에 트리거 문구 박기** — 사용자가 `check-memory` 보고 그대로 발화할 수 있게
- 재개 시 동작:
  1. 트리거 발화 감지 → 메모리 파일 로드
  2. "이전 단계는 다 끝났고 오늘은 ~부터 갈게요" 한 문장 앵커
  3. 다음 시작점부터 진행 + 단계 완료 시 메모리 파일의 체크 표시 갱신
