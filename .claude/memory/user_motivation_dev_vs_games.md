2026-06-19 대화. 사용자가 "요즘 개발(팀프로젝트)이 재미없다, 게임에 다시 빠지려 한다, 게임만 하는 삶은 싫고 개발 꾸준히 하며 돈 벌 수준으로 성장하고 싶다"고 토로 → 진단 + 지속 시스템을 같이 설계함. **이건 주기적으로 재출현하는 패턴**([[user_ai_dependency_anxiety]]와 동류 — 안정기마다 재발). 비슷한 신호("개발 재미 없다", "게임에 빠진다", "저번에 의욕 얘기")가 오면 이 내용을 꺼낼 것.

## 상황 (그때 맥락)
- Post-MVP라 일이 **만들기(빌드) → 회의·운영·전략(뭘 추가해야 사용자가 쓸까)** 쪽으로 쏠림. 사용자는 구현 강·설계/전략 약 자각([[user_dev_style]]) → 약한 쪽·보상 느린 쪽 일이 늘어 재미 ↓.
- 예약해둔 **부트캠프 대기 중**(lame-duck 기간, 현재가 "임시"로 느껴져 의욕 ↓).
- 본인 자가관찰: "잘 하다가 안정기 되면 또 게임에 빠진다" = **안정기 → 게임 드리프트** 반복 패턴.

## 합의한 진단 (핵심 프레임)
- **개발은 게임의 즉각 도파민을 구조적으로 못 이긴다.** 같은 종목(초당 보상)에서 이기려 하면 매번 짐. 그 기준 자체가 함정.
- **보상 통화가 다름:** 게임=고빈도·저진폭·휘발성(한 시간 뒤 0). 개발=저빈도·고진폭·**누적**(실력/제품/돈/정체성으로 쌓임). 게임이 못 주는 건 이 누적 보상.
- **게임은 원인이 아니라 증상.** 일이 보상을 안 주기 시작하니 뇌가 확실한 보상처로 옮긴 것. 의지박약 아님.
- **개발이 게임에 가장 근접하는 순간 = 몰입(flow).** 조건 3개 필요: (1)적당한 난이도 (2)명확한 목표 (3)빠른 피드백. 회의·전략은 셋 다 없음(노잼 당연) / 작은 기능 짜기는 셋 다 있음 → 그래서 작은 빌드 작업으로 보상감 회복이 처방.
- 개발이 꼭 매일 개인시간 쪼개는 취미일 필요 없음. 한 가지에 밥벌이+취미+도파민 다 짊어지면 무너짐. "꾸준히 잘할 만큼 몰입되는 일" 정도면 성공.

## 합의한 6개 지속 시스템 (의지 아니라 구조로)
1. **바닥선 — 절대 안 깨지는 최소치.** 하루 25분 OR 커밋 1개. 실패모드는 "6시간 못 함"이 아니라 "0 → 연속 끊김 → 정체성 붕괴". 본인 기준 표현: 바닥선="오늘 뭔가 개발 관련된 거 하긴 했네", 성장="어제 몰랐던 걸 오늘 알면 유지 중". ceiling 아니라 floor를 지킴.
2. **진입 마찰 설계.** 개발: 자기 전 에디터·브랜치·"내일 첫 줄" 미리 열어둠 + backlog 한 줄 = 다음 할 일(매일 "뭐하지?" 제거). 게임: 런처 로그아웃 등으로 시작 마찰을 개발보다 살짝 높게. (금지 X, 마찰만 조정)
3. **성장 가시화 (게임 XP바 훔쳐오기).** 커밋 연속(GitHub 잔디) + backlog 체크박스 + "이번 주 ship한 것" 한 줄 로그.
4. **게임 = 적이 아니라 보상.** 바닥선 끝낸 뒤 → 게임 OK, 시간 정해서. "다 삭제"는 안정기에 폭발(본인 이력) → 금지는 재발 부름. 일 다음 보상으로 박스에 넣으면 죄책감 사이클 끊김.
5. **돈 목표 구체화.** "막연한 성장" 대신 → **멜로미 프로젝트 = 취업 포트폴리오(실서비스 운영·배포 경험 증거)** + **부트캠프 = 취업으로 가는 다리**. 목표 = "멜로미 ship한 상태로 부트캠프 들어가 취업".
6. **트립와이어(재발 감지선).** 경고 신호: "이틀 연속 커밋 0" 또는 "일하기 전 게임부터 켬". 신호 뜨면 → 그날 바닥선 25분만 하고 끝(완벽주의로 미루지 말기). 자각 빠를수록 회복 쉬움.
- 부트캠프 대기 reframe: "임시기간" → "몸 풀고 들어가면 10배 흡수하는 준비기".

## How to apply (다음에 이 신호 오면)
- 게임에 대해 **도덕적 훈계 금지**(끊어라 X). 일반 생산성 팁 나열 금지. 위 프레임으로 응답.
- 바닥선(1)+마찰설계(2)를 먼저. 트립와이어(6) 가볍게 체크("이틀 커밋 0 안 울렸나").
