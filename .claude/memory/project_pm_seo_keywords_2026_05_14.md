## 적용 옵션 (학습 3·4단계 분석 결과)

| 옵션 | 비용 | 효과 | 적용 시점 |
|---|---|---|---|
| **A. `/` 메타(title/description)에 핵심·영역 일부 녹임** | 5-10분 | 메타 매칭 강화. 본문 부재로 강도 중간 | 즉시 |
| **B. EmptyRoot에 짧은 본문 콘텐츠 추가 (0.5초 노출)** | 15-20분 | 본문 시그널 추가. UX 영향 PM·디자이너 확인 필요 | 즉시~조정 |
| **C. 별도 마케팅 페이지 신설 (`/about` 등)** | 4-6h | 정공법. MVP 후 권장 | MVP 후 |
| **D. 블로그/FAQ 디렉토리 (`/blog/*`, `/faq/*`)** | 콘텐츠 지속 비용 | 정보성 11종 흡수. 콘텐츠 마케팅 게임 | 장기 |

**현실 인식**: 현재 SEO 표면(/, /privacy, /terms) 중 키워드 박을 곳은 `/` 메타뿐. /privacy·/terms 약관 페이지는 마케팅 키워드 부적절 (콘텐츠 톤 불일치). 본문 콘텐츠 페이지 신설이 본격 SEO의 필수 조건.

## 추천 작업 순서 (2026-05-15)

1. **A 즉시 적용** — `/` title + description에 "발달재활 치료사 커뮤니티 · 활동지 공유 · 보수교육" + 영역 키워드 4개 정도 자연스럽게
2. 빌드 + main 머지 + Vercel 배포
3. Google Search Console에서 색인 재요청 (3 페이지)
4. Naver Search Advisor 등록 + sitemap 제출
5. **B 옵션 검토** — EmptyRoot에 본문 추가가 UX적으로 허용되는지 PM·디자이너 확인. 0.5초 잠깐 노출 후 redirect 패턴 자체는 cloaking 아님 (모든 user-agent 동일 HTML)
6. C/D는 MVP 발표 후 백로그로

## 권장 메타 초안 (A 옵션, 검토용)

현재:
```
title: 'Mellti - 치료사 커뮤니티'
description: '발달장애 아동 치료사를 위한 커뮤니티 Mellti.'
```

키워드 녹인 후:
```
title: 'Mellti - 발달재활 치료사 커뮤니티 · 활동지 공유 · 보수교육'
description: '언어치료사·작업치료사·놀이치료사·특수교사 등 발달재활
  치료사를 위한 활동지 공유, 보수교육 정보, 구인구직 커뮤니티 Mellti.'
```

영역 키워드는 description에 4개 정도 넣어 SLP/OT/놀이치료/특수교사 매칭 확보. 나머지 영역(PT/미술/ABA/인지/감각통합/임상심리)은 본문 콘텐츠 페이지 신설 시 담기.

발표 D-day. baseline 검색 결과 부연설명에 /signup 본문(회원가입·이메일·비밀번호)이 자동 추출되는 문제 확인 후, A 단독은 효과 미보장이라 판단해 A+B 동시 적용.

**A — `/` 메타 키워드 적용** (`frontend/src/prerender.tsx` `META_BY_URL['/']`):
- title: `Mellti - 발달재활 치료사 커뮤니티 · 활동지 공유 · 보수교육`
