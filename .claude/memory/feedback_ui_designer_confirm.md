디자이너가 **2026-05-22** 팀을 떠남. 이전 규칙("UI는 디자이너 컨펌 후 구현")은 더 이상 유효하지 않음.

**Why:** 협업 디자이너 퇴팀.

---

## 새 정책

- **기존 Figma 시안 있는 항목**: Figma 시안을 기준으로 구현. MCP `get_design_context` 또는 PNG 2x export로 참조.
- **새 UI (시안 없음)**: 개발자가 직접 결정. AI와 A/B 옵션 논의 후 선택. 결정 내용 memory에 박제.
- **이전 "디자이너 컨펌 대기" 항목**: 블로킹 해소 — 직접 결정 후 진행 가능.

**How to apply:**
- "디자이너 컨펌 필요" 언급 금지. 대신 "기존 Figma 참조 후 구현" 또는 "A/B 옵션 선택" 제안.
- UI 결정 내용은 memory 또는 commit message에 박제(재작업 방지).
- 디자인 품질 기준: 기존 구현물 + Tailwind 디자인 언어와 일관성 유지.

---

## 이전 규칙 (참고용 — 폐기)

백엔드 API 변경이 라벨/아이콘/색상/표시 조건 등 디자인 결정에 영향을 줄 때 "개발 용어 뺀 질문 초안 → 디자이너 확인" 워크플로우는 더 이상 적용 안 함. 대신 직접 합리적인 UX 판단 후 구현.
