**칩 카운트 정책**: 이미지 + 비이미지 파일 **통합 카운트**(`panelItems.length`). 시안 1387:12297 자체는 비이미지 파일만 카운트하는 의도(annotation: "파일 1개일 때는 플로팅 리스트 뜨지 않음")였으나 사용자 요청으로 통합 카운트로 변경(`f3f0d86`). 첨부 0건이면 칩 미렌더(2중 가드: 외부 wrapper + IIFE 내부 `panelItems.length === 0` early return).

**클릭 동작**:

- 2+건 → 시안 1597:10954 플로팅 패널 노출(`DropdownMenu` 기반).

**플로팅 패널 구조**:

- 상단 bundle: '전체 다운로드' (`border-b`로 리스트와 시각 구분, `Download` 24px + text-sm 볼드).
- 하단 bundle: 이미지+파일 통합 리스트, 행별 아이콘 분기(이미지=`ImageIcon`, 파일=`FileText`).
- '전체 다운로드'는 브라우저 동시 다운로드 제한 회피를 위해 **150ms 간격 순차 트리거**(`setTimeout(..., i * 150)`).
- 각 다운로드마다 GA4 `download` 이벤트 발생(KPI=행위 횟수).

**미리보기 파일명**: 칩 우측에 1줄(`truncate min-w-0`). 우선순위 = 첫 비이미지 파일 > 첫 이미지(`files[0]?.originalFilename ?? images[0]?.originalFilename`).

**Why**: 사용자가 "첨부 = 이미지 + 파일 통합" 멘탈 모델 선호. 캐러셀(`useDragScroll` 기반 가로 드래그)은 시각화 전담, 다운로드는 칩 → 패널로 일원화. 캐러셀 내 개별 다운로드 링크(`<a download>`)는 `ac65bfc`에서 제거됨.

**How to apply**: 첨부 영역 후속 시안 정합/기능 확장 시 이 통합 카운트 모델 기반으로 확장. 시안과 다른 부분은 이 메모리가 우선.
