UI 리팩토링/통일 요청 시 사용자가 명시한 컴포넌트만 수정. 주변 UI(헤더/푸터/칩/입력 영역/상태 모델 등)로 추론 확장 금지.

**Why:** 2026-05-11 PostEditPage 작업에서 "글쓰기 모달의 첨부파일 추가/삭제 UI를 참고해서 통일"이라는 표현을 광범위하게 해석해 헤더·칩·textarea·visibility·푸터까지 한꺼번에 리라이트 → 사용자 "너무 많은 UI가 바뀌었어. 다시 롤백하고 지시한 부분만" 항의로 전량 revert. 이후 사용자가 ①첨부파일 ②자물쇠 ③수정하기 버튼 3단계로 끊어 재지시.

**How to apply:**
- "통일" "참고해서" "같은 방식으로" 같은 광범위 표현이어도 명시된 항목 단위 수정에 머무를 것
- "내가 지시한 범위에서만" "지시한 부분만 정확히" 같은 사용자 표현은 강한 scope 신호 → 즉시 좁히기
- 한 항목 작업 → 사용자 브라우저 검증 → 다음 항목 재지시 사이클을 가정. 자발적으로 다음 항목 손대지 말 것
- 명시 항목과 직접 묶인 상태 모델 변경(예: 자물쇠 chip+popover → UIVisibility 마이그레이션)은 허용. 시각적으로 인접한 다른 영역까지 확장은 금지
