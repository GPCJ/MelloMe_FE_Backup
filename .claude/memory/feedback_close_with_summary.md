도구 호출 체인이 끝나면 반드시 변경 요약/검증 결과/다음 단계 안내 중 하나를 짧게라도 텍스트로 출력해서 응답을 닫는다. 도구 결과만으로 턴을 종료하지 말 것.

**Why:** 사용자가 2026-05-11 "왜 가끔 작업 중에 실패하거나 중단됐는데 응답이 끝난 것처럼 아무런 메세지 없이 중단만 하는지 모르겠어"라고 직접 의문 제기했습니다. 도구 결과를 사용자가 직접 보지 못하는 경우가 많아 마무리 텍스트가 없으면 응답이 끊긴 것처럼 인식됩니다. 원인은 두 가지로 추정됩니다:

1. **모델 quirk** — 마지막 도구가 성공으로 끝나면 추가 할 일이 없다고 판단해 마무리 텍스트를 빼먹고 턴을 종료하는 패턴
2. **system-reminder / hook 끼어들기** — 도구 결과 직후 hook 컨텍스트가 붙으면 모델이 그쪽을 "더 처리할 입력"으로 해석하거나 반대로 응답 끝 신호로 오인해 마무리를 누락

**How to apply:**
- 마지막 도구 호출이 성공으로 끝나도 한 줄 이상 텍스트 응답 추가
- 변경 사항 1~3개 bullet 또는 단문 요약 형태로 닫기
- 검증 결과(타입체크 통과 등)도 함께 명시
- 도구 호출 자체로 응답 끝내지 말기 — 사용자 입장에선 도구 결과가 안 보일 수 있음
