노트패드 Priority Context와 관련 메모리를 대조해 stale 여부를 자동 확인하고, 최신화가 필요하면 갱신 후 결과를 보여줘.

## 실행 순서

1. **노트패드 읽기** — 세션 시작 시 주입된 `[NOTEPAD - Priority Context]` 사용 (별도 파일 읽기 X)
2. **메모리 대조** — `.claude/memory/MEMORY.md`의 `## 작업 관리` 섹션을 읽고, 각 노트패드 항목과 관련된 메모리 파일 링크를 찾아 해당 파일 읽기
3. **Stale 감지** — 노트패드 설명과 메모리 현황이 다르면 stale 판정
   - 예: 노트패드 "맥북서 개발" → 메모리 "C2 완료, BE 대기"
   - 예: 노트패드 "★1순위" → 메모리 "블로킹 상태"
4. **자동 갱신** — stale 항목 있으면 `notepad_write_priority`로 최신 내용 교체 (500자 이내)
5. **결과 출력** — 갱신됐으면 `🔄 자동 갱신됨` 한 줄 앞에 표시, 최신이면 그냥 출력

## 출력 포맷

```
**[오늘 ①]** 제목
1줄 메모
다음: 세부항목1 / 세부항목2 / ...

**[대기 ★]** 제목
블로커1 — 설명
블로커2 — 설명

**[대기]** 항목명 — 블로커 한줄
**[대기]** 항목명 — 블로커 한줄
```

- `·` 기호로 이어 쓰지 말고 줄바꿈으로 끊어서 출력

## 태그 규칙

- `[오늘 ①②]` = 지금 실행 가능한 항목, 번호 = 우선순위 순
- `[이어가기]` = 워킹트리에 미완 작업이 있는 항목
- `[대기 ★]` = 가장 중요한 블로킹 항목 (BE 대기 / 기기 필요 등)
- `[대기]` = 나머지 블로킹 항목

3개 초과는 생략. 각 항목은 제목 + 1줄 메모.
